# Lienzo de gasto a capacidad

**Capítulo 1** · Entregable E1 · Tiempo estimado: 90 minutos con el comité

Reclasifica el gasto tecnológico según **la capacidad que compra**, no según la partida
contable en la que aparece. Se rellena una vez al año, **antes** de la reunión de
presupuestos.

---

## Parte 1 · Reclasificación

Una fila por partida del presupuesto real. No reagrupar antes de clasificar.

| Partida | € | Naturaleza | Si recorto 50 %, ¿qué pasa a 3 meses? | ¿Y a 24 meses? | Decisión de negocio que habilita o bloquea | ¿Se puede revertir el recorte? Coste y plazo |
|---|---|---|---|---|---|---|
| | | | | | | |
| | | | | | | |
| | | | | | | |

**Naturalezas** (elegir una, no vale «mixta»; si una partida es realmente mixta, se parte en dos filas):

| Código | Naturaleza | Qué compra | Cómo se decide |
|---|---|---|---|
| **O** | Operar | Que hoy funcione lo que ya existe | Eficiencia. Aquí el *benchmark* sectorial sí informa. |
| **S** | Sostener capacidad | Que dentro de dos años siga siendo posible cambiar las cosas | Nivel mínimo de seguridad. Recortar aquí es vender opciones. |
| **A** | Ampliar capacidad | Poder hacer lo que hoy no podemos | Se justifica por la decisión de negocio que desbloquea. |
| **X** | Apostar | Explorar algo de retorno incierto | Presupuesto de riesgo acotado (cap. 7). |

> **Regla de la asimetría.** La diferencia entre la columna de 3 meses y la de 24 meses **es**
> la opción que se está vendiendo. Cuando las dos respuestas son «nada», has encontrado grasa
> real: recórtala sin remordimiento.

## Errores al rellenarlo

- **Clasificar el propio presupuesto sin contraparte.** Existe un incentivo evidente a
  reetiquetar Operar como Sostener. La clasificación la hace un grupo con intereses
  contrapuestos, no el área que pide el dinero.
- **Responder «sería un desastre» en las columnas de recorte.** No sirve. Hay que decir qué
  deja de poder hacerse y cuándo.
- **Redactar la columna de decisión de negocio en lenguaje técnico.** Si un director
  comercial no la entiende sin traducción, está mal escrita.
- **Estimar el tiempo de cambio.** Es un dato de archivo. Buscarlo.
