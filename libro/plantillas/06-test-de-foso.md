# Test de foso

**Capítulo 6** · Entregable E6

Somete una ventaja competitiva declarada a ocho preguntas. **Regla del test: una afirmación
sin la evidencia requerida cuenta como NO.** Sin esa regla, todas las empresas pasan.

---

## Identificación

**Ventaja que se afirma tener:**
> ______________________________________________________________________

**Tipo declarado:** escala · efectos de red · costes de cambio · marca · recurso único ·
proceso superior · regulación · datos

---

## Las ocho preguntas

| # | Pregunta | Evidencia requerida para responder SÍ | Resp. |
|---|---|---|---|
| 1 | ¿Un competidor con recursos y voluntad tardaría **más de 18 meses** en igualarlo? | Descripción concreta de qué tendría que hacer y cuánto le llevaría cada paso | |
| 2 | ¿La ventaja **crece** con nuestro tamaño, en lugar de solo acompañarlo? | Serie temporal que muestre mejora del indicador de ventaja al crecer, no solo crecimiento | |
| 3 | ¿Podría replicarla alguien **comprándola** a un proveedor? | Comprobación de que la capacidad no se vende como producto o servicio a terceros | |
| 4 | ¿El cliente **soportaría un coste real** al cambiarse a un competidor? | Coste cuantificado: dinero, tiempo, datos que perdería, reaprendizaje | |
| 5 | ¿La ventaja resiste que el cliente **use los dos** a la vez? | Análisis de multi-pertenencia: ¿puede tener ambos proveedores sin penalización? | |
| 6 | ¿Depende de **algo nuestro** y no de una condición del mercado que puede desaparecer? | Identificación del activo o proceso propio del que depende | |
| 7 | ¿Sobreviviría si **el precio de la tecnología subyacente cayera a cero**? | Razonamiento sobre qué queda cuando la capacidad se vuelve accesible para todos | |
| 8 | ¿Existe **evidencia observable** de que ya está funcionando? | Precio premium sostenido, menor rotación, menor coste de captación, cuota creciente | |

---

## Bloque adicional: si la ventaja alegada es un efecto de red

Las cuatro se responden con SÍ o el efecto de red no es defendible.

- [ ] **¿Es global o local?** ¿El usuario nuevo de una ciudad aporta valor a los usuarios de
      otra? *Si el efecto es local, no hay una barrera: hay tantas barreras pequeñas y
      franqueables como mercados locales.*
- [ ] **¿Es de un lado o cruzado?** ¿Quién gana valor cuando entra un usuario nuevo?
- [ ] **¿Decae con el tamaño?** ¿A partir de cierto punto un usuario más aporta menos, o
      incluso resta (ruido, congestión, peor emparejamiento)?
- [ ] **¿Es exclusivo?** ¿O el usuario puede estar en dos plataformas a la vez sin coste? *La
      multi-pertenencia es lo que destruye la mayoría de los efectos de red alegados.*

## Bloque adicional: si la ventaja alegada son los datos

Las tres condiciones deben cumplirse **a la vez**.

- [ ] **El producto mejora de forma perceptible con el uso.** ¿Percibe el cliente la mejora,
      o solo la medimos internamente?
- [ ] **Esa mejora atrae más uso.** ¿Existe el bucle, o los datos solo alimentan informes?
- [ ] **El competidor no puede obtener datos equivalentes.** ¿Comprándolos? ¿Generándolos?
      ¿Con muchos menos y un modelo mejor?

**La pregunta que cierra:** ¿en qué punto se satura? Si a partir de cierto volumen más datos
no producen un producto mejor, la ventaja tiene techo y por tanto fecha de caducidad.

---

## Veredicto

| Respuestas SÍ | Clasificación | Cómo se gestiona |
|---|---|---|
| **7–8** | **Foso** | Invertir en profundizarlo. Defender. Horizonte largo. |
| **4–6** | **Ventana** | **Monetizar rápido.** No invertir en profundizarla: se va a cerrar. Preparar la siguiente. |
| **0–3** | **Espejismo** | Dejar de basar el plan en ella. Buscar la ventaja real, si existe. |

> El error más caro de este capítulo es **tratar una ventana como si fuera un foso**: invertir
> en profundizar algo que se va a cerrar, en lugar de exprimirlo mientras dura. Se comete con
> las mejores intenciones y es difícil de detectar desde dentro, porque los primeros años una
> ventana y un foso se comportan igual.
